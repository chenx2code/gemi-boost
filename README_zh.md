# GemiBoost - Table of Contents for Gemini

[English](./README.md) | 简体中文

**GemiBoost** 是一款 Chrome 扩展程序，旨在增强Google Gemini网页版 (`gemini.google.com`) 的使用体验。

## 功能特性

- **动态目录 (TOC)**：自动生成侧边栏，为长对话中的所有提问建立索引。
- **平滑导航**：点击目录中的任何项目即可瞬间滚动到聊天中的相应位置。
- **导出为 Markdown**：一键导出完整对话为结构清晰的标准 Markdown (`.md`) 文件，原生保留代码高亮语言、LaTeX 数学公式、表格与思考过程。

## 安装说明

由于此扩展程序尚未发布到 Chrome Web Store，您可以通过以下方式手动安装：

### 方法一：下载 Release 压缩包安装（推荐）
1. 前往项目的 [Releases](../../releases) 页面。
2. 下载最新版本的 `gemi-boost-vX.X.X.zip` 压缩包。
3. 将下载的 zip 文件解压到您电脑上的一个文件夹中。
4. 打开 Google Chrome 浏览器并前往 `chrome://extensions/`。
5. 在右上角启用 **“开发者模式”**。
6. 点击 **“加载已解压的扩展程序”** 并选择刚刚解压的文件夹。
7. 打开 [Gemini](https://gemini.google.com/) 开始聊天！

### 方法二：通过源码安装
1. 下载或克隆此代码库。
2. 打开 Google Chrome 浏览器并前往 `chrome://extensions/`。
3. 在右上角启用 **“开发者模式”**。
4. 点击 **“加载已解压的扩展程序”** 并选择 `gemi-boost` 源码文件夹。
5. 打开 [Gemini](https://gemini.google.com/) 开始聊天！
