**GemiBoost** is a Chrome extension designed to enhance your experience on Google Gemini Web (`gemini.google.com`).

## Features

- **Dynamic Table of Contents (TOC)**: Automatically generates a sidebar indexing all your questions in a long conversation.
- **Smooth Navigation**: Click any item in the TOC to instantly scroll to that part of the chat.
- **Export to Markdown**: Export entire chat conversations into clean, formatted Markdown (`.md`) files with a single click, preserving code blocks, syntax highlighting, LaTeX math formulas, tables, and thinking processes.

## Installation

Since this extension is not yet on the Chrome Web Store, you can install it manually using one of the methods below:

### Method 1: Install from Release (Recommended)
1. Go to the [Releases](../../releases) page.
2. Download the latest `gemi-boost-vX.X.X.zip` file.
3. Extract the zip file to a folder on your computer.
4. Open Google Chrome and navigate to `chrome://extensions/`.
5. Enable **"Developer mode"** in the top right corner.
6. Click **"Load unpacked"** and select the extracted folder.
7. Open [Gemini](https://gemini.google.com/) and start chatting!

### Method 2: Install from Source
1. Download or clone this repository.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **"Developer mode"** in the top right corner.
4. Click **"Load unpacked"** and select the `gemi-boost` folder.
5. Open [Gemini](https://gemini.google.com/) and start chatting!
